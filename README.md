# Online Quiz and Assessment System

## Project Description

The Online Quiz and Assessment System is a web-based application designed to conduct online quizzes and assessments.

The system allows teachers to create and manage quizzes, while students can participate in quizzes and receive their results automatically.

## Problem Statement

Traditional quiz and assessment processes require manual question management, answer evaluation, score calculation, and result maintenance.

This project aims to develop an online system that automates quiz creation, student participation, evaluation, score calculation, and result history.

## Objectives

- Provide secure student and teacher login.
- Allow teachers to create and manage quizzes.
- Allow teachers to add, edit, and delete questions.
- Allow students to participate in quizzes.
- Automatically evaluate student answers.
- Calculate quiz scores automatically.
- Store quiz results.
- Provide result history.
- Provide separate teacher and student dashboards.

## Target Users

### Student
- Register and login
- View available quizzes
- Attend quizzes
- Submit answers
- View scores
- View result history

### Teacher
- Login
- Create quizzes
- Manage questions
- Edit and delete quizzes
- View student results

## Functional Requirements

1. Student registration and login
2. Teacher login
3. Role-based dashboards
4. Quiz creation
5. Question management
6. Quiz participation
7. Automatic evaluation
8. Score calculation
9. Result storage
10. Result history

## Non-Functional Requirements

- Performance

- Framework: Express.js
- Database: MongoDB
- API Testing: Postman
- Authentication: JWT
